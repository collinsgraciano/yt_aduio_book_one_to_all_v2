# 系统工具使用教程

## 功能概览

系统工具页面提供数据库备份、恢复、云盘同步、项目导出的 Web 管理界面，无需 SSH 命令行操作。

访问地址：`http://VPS_IP:59386/system-tools`

侧边栏点击「系统工具」进入。

---

## 一、前置准备：配置 rclone（云盘功能）

### 1.1 安装 rclone

在 VPS 宿主机上执行（只需一次）：

```bash
curl https://rclone.org/install.sh | bash
```

验证安装：

```bash
rclone version
```

### 1.2 配置 Google Drive

```bash
rclone config
```

按提示操作：

```
n/s/q> n                    # 新建远程
name> gdrive                # 命名为 gdrive
Storage> drive              # 选 Google Drive（输入 drive 或对应序号）
client_id>                  # 直接回车，留空用默认
client_secret>              # 直接回车
scope> 1                    # 完全访问
root_folder_id>             # 直接回车
service_account_file>       # 直接回车
Edit advanced config? n     # 不编辑高级配置
Use auto config? y           # 自动配置
```

此时终端会显示一个 URL，复制到本地浏览器打开：

1. 登录 Google 账号
2. 授权 rclone 访问 Google Drive
3. 复制返回的授权码
4. 粘贴回终端

```
Configure as Shared Drive? n  # 不用共享云盘
y/q> y                       # 确认保存
```

### 1.3 配置 Mega

```bash
rclone config
```

按提示操作：

```
n/s/q> n                    # 新建远程
name> mega                  # 命名为 mega
Storage> mega               # 选 Mega（输入 mega 或对应序号）
user> 你的Mega邮箱
password> 你的Mega密码       # 输入两次确认
y/q> y                      # 确认保存
```

> Mega 不需要浏览器授权，直接输入邮箱密码即可。

### 1.4 验证配置

```bash
# 查看已配置的远程
rclone listremotes
# 应显示:
# gdrive:
# mega:
```

### 1.5 验证容器内可用

```bash
docker exec audiobook_web rclone listremotes
# 应显示同样的输出
```

> rclone 配置文件在宿主机 `/root/.config/rclone/rclone.conf`，已挂载到容器内（只读）。

## 二、备份管理

### 2.1 本地备份

点击「立即备份」按钮。

- 执行 `pg_dump` 全库导出 → gzip 压缩
- 保存到 `backups/audiobook_backup_YYYYMMDD_HHMMSS.sql.gz`
- 自动保留最新 7 个备份，多余的自动删除
- 执行过程实时显示日志

### 2.2 云盘备份

点击「云盘备份」按钮。

- 先执行本地备份（同上）
- 同时备份 `.env` 配置文件
- 上传到 Google Drive (`gdrive:audiobook_backup/`)
- 上传到 Mega (`mega:audiobook_backup/`)
- 云端也保留最新 7 个备份
- 如果某个云盘未配置，自动跳过，不影响另一个

### 2.3 连通性测试

点击「测试」按钮（推荐首次使用前先测试）。

- 备份一个小的测试文件（仅表结构，不导数据）
- 上传到 gdrive 和 mega 验证连通性
- 测完自动清理本地和云端的测试文件

### 2.4 备份文件列表

页面下方表格显示所有本地备份文件：

| 文件名 | 大小 | 时间 | 操作 |
|--------|------|------|------|
| audiobook_backup_20260724_031700.sql.gz | 15.2 MB | 2026-07-24 03:17 | 🗑️ 删除 |

点击删除按钮可删除单个备份文件。

### 2.5 云端备份列表

切换来源（Google Drive / Mega）查看云端备份文件。点击「恢复」按钮可直接跳转到恢复页面并自动填入文件名。

## 三、恢复数据库

### 3.1 从本地备份恢复

1. 在下拉框选择备份文件
2. 勾选「我确认要覆盖当前数据库数据」
3. 点击「恢复数据库」按钮

恢复过程：
- 断开所有数据库连接
- DROP + CREATE 数据库
- 导入备份数据
- 更新统计信息
- 显示表行数验证

### 3.2 从云盘恢复

1. 选择来源（Google Drive / Mega）
2. 输入文件名（留空则自动选最新备份）
3. 勾选确认
4. 点击「从云盘恢复」

恢复过程：
- rclone 下载备份文件到本地
- 断开连接 → DROP → CREATE → 导入数据

> **警告**：恢复操作会覆盖当前数据库的所有数据。恢复完成后建议重启 Web 服务：`docker compose restart web`

## 四、项目导出

点击「导出迁移包」按钮。

导出内容：

| 文件 | 说明 |
|------|------|
| `db_backup.sql.gz` | 数据库全量备份（表结构 + 数据） |
| `env_backup` | .env 配置文件（含 SECRET_KEY、POSTGRES_PASSWORD） |
| `table_counts.txt` | 表行数统计 |

打包为 `backups/migration_bundle_YYYYMMDD_HHMMSS.tar.gz`。

页面下方表格显示所有本地迁移包文件。

## 五、实时日志

所有操作执行时，页面底部的「执行日志」区域实时显示输出：

- 黑色终端风格，自动滚动到底部
- 1 秒轮询增量更新
- 完成后显示退出码（✅ 绿色=成功 / ❌ 红色=失败）
- 可点击「清空」按钮清除日志

同一时间只允许一个任务运行，第二个请求会返回 409 提示等待。

## 六、定时备份设置

虽然 Web 页面可以手动备份，建议同时设置 crontab 自动备份：

### 6.1 本地定时备份

```bash
crontab -e
```

添加：

```
17 3 * * * cd /root/audiobook && docker exec audiobook_web bash scripts/db_backup/db_backup_auto.sh >> backups/cron.log 2>&1
```

### 6.2 云盘定时备份（推荐）

```
37 3 * * * cd /root/audiobook && docker exec audiobook_web bash scripts/db_backup/db_backup_cloud.sh >> backups/cron.log 2>&1
```

> 每天 03:17/03:37 自动执行，日志写入 `backups/cron.log`。

## 七、常见问题

### Q: 页面顶部显示「rclone 未安装」

A: 容器镜像可能未重建。执行：
```bash
cd /root/audiobook && git pull && bash scripts/deploy/git-server-deploy.sh
```

### Q: 云盘备份显示「远程未配置」

A: 在宿主机执行 `rclone config` 配置对应远程，然后重启容器：
```bash
docker compose restart web
```

### Q: Google Drive 授权失败

A: 确保 VPS 能访问外网。rclone 的 `Use auto config? y` 需要在有浏览器的机器上操作。如果 VPS 没有浏览器：
1. 在本地电脑安装 rclone
2. 执行 `rclone authorize "drive"` 获取 token
3. 将 token 复制到 VPS 的 rclone 配置中

### Q: 备份失败，日志显示 pg_dump 连接超时

A: 检查 PostgreSQL 容器是否运行：
```bash
docker ps | grep postgres
```

### Q: 恢复后 Web 页面无法访问

A: 恢复操作会断开数据库连接，可能导致 Web 服务异常。执行：
```bash
cd /root/audiobook && docker compose restart web
```
